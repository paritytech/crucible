# Crucible icon concept

A monochrome **forge cross**: Polkadot's six-dot orbit, a bold central X, and a small
crucible-shaped opening in negative space. This is a design proposal, not official Polkadot branding.

- `crucible-icon.svg`: editable vector with a transparent background.
- `crucible-icon.png`: transparent 1024 px export.
- `crucible-icon-preview.png`: black mark on white for presentation.

The six-dot geometry comes from the [Polkadot marketing asset repository](https://github.com/shawntabrizi/Polkadot-Marketing),
which distributes its assets under CC0. The central X is original to this concept.
Review the composition against Polkadot's [brand guidance](https://polkadot.com/community/brand-hub)
before adopting it as a public project identity.
